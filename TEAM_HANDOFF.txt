7. GEOTAGGING
============================================================

Geotagging is implemented.

Each detection contains:

- latitude
- longitude
- event number
- ping number
- sensor depth
- altitude
- heading
- channel
- across-track offset
- ground range
- slant range
- bounding box
- confidence
- class

Current geotagging method:

XTF ping navigation + sonar pixel geometry

IMPORTANT:
The demonstration uses synthetic navigation data.
Coordinates are demonstration data and are not survey-grade.
